# Rich Street Food

Учебный проект по веб-технологиям: сайт доставки бизнес-ланчей.
Меню загружается с API Московского Политеха, заказ собирается в браузере,
история заказов хранится на сервере, лендинг свёрстан на Bootstrap 5.

![Главная страница](images/obed.jpg)

## Стек

- HTML5, CSS3 (Flexbox, Grid, медиазапросы)
- JavaScript (ES6+), без сборщика и фреймворков
- Bootstrap 5.3 по CDN — только на странице лендинга
- REST API: `fetch` и `XMLHttpRequest`, авторизация по `api_key`
- `localStorage` — сохранение выбранных блюд

## Страницы

| Файл | Что делает |
|---|---|
| `index.html` | Главная: описание компании, преимущества, контакты |
| `menu.html` | Меню с API: карточки блюд, выбор, закреплённая панель заказа |
| `order.html` | Оформление заказа: состав, форма доставки, отправка на сервер |
| `orders.html` | История заказов: таблица, просмотр, редактирование, удаление |
| `landing/index.html` | Адаптивный лендинг на Bootstrap 5 |

## Запуск

Проект статический, сборка не нужна. Открывать файлы двойным кликом нельзя:
браузер заблокирует запросы к API с `file://`. Нужен локальный сервер:

```bash
python -m http.server 8000
```

Затем открыть <http://localhost:8000>. Подойдёт и расширение Live Server в VS Code.

### Безопасность

Сайт полностью клиентский, поэтому ключ всё равно виден в DevTools любого посетителя.
Не публикуйте личный ключ и не коммитьте `config.js` / `.env`.
Если ключ уже попадал в коммит, `.gitignore` его не уберёт — запросите новый ключ в СДО.

## Проверка

- `menu.html` — 30 карточек, выбор сохраняется после перезагрузки;
- `order.html` — состав совпадает с меню, заказ уходит на сервер;
- `orders.html` — создание, изменение и удаление заказа отражаются в списке;
- `landing/index.html` — все блоки перестраиваются под ширину экрана.

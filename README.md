# Rich Street Food

Учебный проект по веб-технологиям: сайт доставки бизнес-ланчей.
Меню загружается с API Московского Политеха, заказ собирается в браузере,
история заказов хранится на сервере, лендинг свёрстан на Bootstrap 5.

![Главная страница](images/obed.jpg)

## Стек

- HTML5, CSS3 (Flexbox, Grid, медиазапросы)
- JavaScript (ES6+), без сборщика и фреймворков
- Bootstrap 5.3 по CDN — только на странице лендинга
- REST API: `fetch` и `XMLHttpRequest`, авторизация по `api_key`
- `localStorage` — сохранение выбранных блюд

## Страницы

| Файл | Что делает |
|---|---|
| `index.html` | Главная: описание компании, преимущества, контакты |
| `menu.html` | Меню с API: карточки блюд, выбор, закреплённая панель заказа |
| `order.html` | Оформление заказа: состав, форма доставки, отправка на сервер |
| `orders.html` | История заказов: таблица, просмотр, редактирование, удаление |
| `landing/index.html` | Адаптивный лендинг на Bootstrap 5 |

## Что реализовано

**Меню и заказ (лабы 7–8)**

- загрузка блюд с API и локальные картинки-заглушки;
- выбор блюд, повторное добавление не дублирует позицию;
- состав заказа и сумма в закреплённой панели;
- хранение выбранных id в `localStorage` и восстановление после перезагрузки;
- проверка комбо: ссылка «Оформить заказ» активна только при корректном составе;
- отправка заказа через `POST /labs/api/orders`, уведомления об ошибках.

**История заказов (лаба 9)**

- список заказов текущего пользователя, новые сверху;
- состав, стоимость и время доставки в каждой строке;
- модальные окна «Подробнее», «Редактирование», «Удаление»;
- `PUT` только с изменившимися полями и `DELETE` с подтверждением;
- обновление списка и уведомления после операций;
- на телефоне таблица превращается в карточки.

**Лендинг (лаба 10)**

- сетка Bootstrap: hero, преимущества, CTA, форма и контакты;
- `navbar` с бургером на мобильных;
- проверка полей формы через `needs-validation`;
- проверено на ширинах 1280, 768 и 390 px.

## Запуск

Проект статический, сборка не нужна. Открывать файлы двойным кликом нельзя:
браузер заблокирует запросы к API с `file://`. Нужен локальный сервер:

```bash
python -m http.server 8000
```

Затем открыть <http://localhost:8000>. Подойдёт и расширение Live Server в VS Code.

## Настройка API

Ключ выдаётся в СДО Московского Политеха. В репозиторий он не попадает.

1. Скопируйте `scripts/config.example.js` в `scripts/config.js`.
2. Впишите свой ключ:

```js
window.API_URL = 'https://web-basics-api-gagashaggy.msk1.amvera.tech';
window.API_KEY = 'ваш-api-key';
```

3. Те же значения можно хранить в `.env` (файл в `.gitignore`):

```env
API_URL=https://web-basics-api-gagashaggy.msk1.amvera.tech
API_KEY=ваш-api-key
```

`config.js` подключается в HTML перед `api.js`, поэтому страницы сразу видят настройки.
`.env` — просто локальная копия секретов, сам сайт его не читает.

### Безопасность

Сайт полностью клиентский, поэтому ключ всё равно виден в DevTools любого посетителя.
Не публикуйте личный ключ и не коммитьте `config.js` / `.env`.
Если ключ уже попадал в коммит, `.gitignore` его не уберёт — запросите новый ключ в СДО.
